# EduQuest-Gamified-E-Learning-Platform
The rise in digital learning has provided students with the opportunity to learn anywhere at any time. However, many conventional e-learning environments fail to retain learner motivation, due to a passive approach to delivering content, as well as lack of active elements. EduQuest is a gamified e-learning environment designed to alleviate these important concerns by providing various game-like elements to support active learning and continued engagement in education. 
EduQuest is a game-based e-learning solution that includes engagement-driven components like points (XP), badges, leaderboards, and a course unlocking feature using the points or XP earned. This keeps learners not only reading the knowledge but also encourages them to move forward through challenges, quizzes, and  course levels. 
EduQuest provides a secure user management system, with separate roles for students and administrators. The administrator (the creator) can upload and manage courses, while students can register, log in, and access learning material that is structured. A quiz provides an opportunity for the learners to test their knowledge and receive experience points (XP) as an award. While conventional e-learning environments do not include XP or other software designed to elevate engagement, the EduQuest environment allows advanced e-learning instructors to lock courses until students earn enough XP to continue in the course. Other gamification elements including leaderboards, badges, and achievements further support learner engagement and create a socially appropriate environment for learner competition.
